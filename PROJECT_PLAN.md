# Mechanic Shop Website

## Main Goal

Allow customers to request an appointment.

## Pages

- Home
- Services
- About
- Contact
- Request Appointment

## Required Features

- Responsive navigation
- Appointment request form
- Customer information
- Vehicle information
- Preferred appointment date
- Service selection
- Problem description
- Sunday unavailable
- PostgreSQL database
- Mobile-friendly design

## Future Features

- Customer registration/login
- Admin dashboard
- Available time slots
- Appointment confirmation
- Appointment cancellation
- Email notifications
- Text notifications
- Online payments
